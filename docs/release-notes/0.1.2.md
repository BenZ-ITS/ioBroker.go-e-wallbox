## English

### What changed

- The adapter is now called `go-e-wallbox`; the package is `iobroker.go-e-wallbox` and the repository
  `BenZ-ITS/ioBroker.go-e-wallbox`.
- This is the first version published on npm.
- Every change is now tested on Linux, Windows and macOS with Node.js 22, 24 and 26.

### Impact

- The adapter can be installed from npm. It appears in the adapter list of the admin interface once it is listed in
  the ioBroker repository.
- An installation of a package file named `goe-wallbox` is not updated to `go-e-wallbox`; install `go-e-wallbox` and
  enter the wallboxes again.
- States, settings and behaviour are unchanged apart from the name.

### Why

- ioBroker derives the adapter name from the repository name, and the repository is now `ioBroker.go-e-wallbox`.
- Publishing on npm is required for an entry in the ioBroker repository.

- Der Adapter heißt jetzt `go-e-wallbox`; das Paket ist `iobroker.go-e-wallbox`, das Repository

- Datenpunkte, Einstellungen und Verhalten sind bis auf den Namen unverändert.

### Hintergrund

- ioBroker leitet den Adapternamen aus dem Namen des Repositorys ab, und das heißt jetzt `ioBroker.go-e-wallbox`.
- Die Veröffentlichung auf npm ist Voraussetzung für einen Eintrag im ioBroker-Verzeichnis.
