## English

### What changed

- The settings page, the title and the description of the adapter are available in all languages of ioBroker
  (English, German, Russian, Portuguese, Dutch, French, Italian, Spanish, Polish, Ukrainian, Chinese). English and
  German are written by hand, the other languages are machine translated.
- The adapter requires admin 7.6.20 or newer (before: 7.6.17).
- The package is published to npm directly by the GitHub workflow of this repository and carries a provenance
  statement.
- The adapter is marked as not installable directly from GitHub, and the package names a contact address.

### Impact

- Users of the admin interface in one of the newly supported languages see the settings page in their language.
- Systems with an admin older than 7.6.20 have to update admin first.
- On npm, the provenance statement shows which repository and which workflow run built the package.
- States, settings and behaviour are unchanged.

### Why

- These are requirements of the ioBroker adapter repository, which the adapter is going to be added to.
- Provenance makes it possible to check that the published package was built from this repository.

## Deutsch

### Was sich geändert hat

- Einstellungsseite, Titel und Beschreibung des Adapters gibt es in allen Sprachen von ioBroker (Englisch, Deutsch,
  Russisch, Portugiesisch, Niederländisch, Französisch, Italienisch, Spanisch, Polnisch, Ukrainisch, Chinesisch).
  Englisch und Deutsch sind von Hand geschrieben, die übrigen Sprachen maschinell übersetzt.
- Der Adapter verlangt Admin 7.6.20 oder neuer (bisher 7.6.17).
- Das Paket wird direkt vom GitHub-Workflow dieses Repositorys auf npm veröffentlicht und trägt einen
  Herkunftsnachweis (Provenance).
- Der Adapter ist als nicht direkt von GitHub installierbar gekennzeichnet, und das Paket nennt eine Kontaktadresse.

### Auswirkungen

- Wer die Admin-Oberfläche in einer der neu unterstützten Sprachen nutzt, sieht die Einstellungsseite in dieser
  Sprache.
- Systeme mit einem Admin älter als 7.6.20 müssen zuerst den Admin aktualisieren.
- Auf npm zeigt der Herkunftsnachweis, aus welchem Repository und welchem Workflow-Lauf das Paket gebaut wurde.
- Datenpunkte, Einstellungen und Verhalten sind unverändert.

### Hintergrund

- Das sind Anforderungen des ioBroker-Adapterverzeichnisses, in das der Adapter aufgenommen werden soll.
- Mit dem Herkunftsnachweis lässt sich prüfen, dass das veröffentlichte Paket aus diesem Repository gebaut wurde.
